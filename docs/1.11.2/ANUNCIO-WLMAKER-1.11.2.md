# Lanzamiento — wlmaker 1.11.2

El equipo de **Blondon Boys** anuncia **wlmaker-cli v1.11.2**.

**Corrección:** el paquete de 1.11.1 se publicó con un build desactualizado. Esta versión deja en el CLI instalado las mejoras del editor de notas.

> Nota: esta es una entrada del blog **solo para el CLI**. La extensión VIBE sigue en 1.2.1.

---

## Qué se corrige

| Mejora | Estado en 1.11.2 |
| --- | --- |
| **Mantener tags** | Disponible en el editor de notas IR/RC |
| **NO TICKET filtrable** | Chip `NO-TICKET` en Filters |
| **Loader de lanzamiento** | Animación mientras se buscan tags y se recolectan PRs |

Si instalaste 1.11.1 y no veías esos cambios, actualiza a **1.11.2**.

---

## Instalación

```bash
pnpm add -g wlmaker@latest
# o
npm i -g wlmaker@latest
```

Abre `wlmaker` → **IR Release** o **RC Release** y mira el editor de notas.

**Las mejoras de 1.11.1, ya en el CLI.**
